# Public, live 1IEP software smoke example

Run from the repository with `.venv/bin/python examples/run_live.py`. This runs RDKit → Meeko → Vina → SDF reconstruction → PoseBusters and attempts PLIP if installed. It writes real logs, scores, pose files, event JSONL, CSV, a Markdown report and a machine-readable manifest under `runs/live-smoke/`. Re-running unchanged inputs resumes verified compound checkpoints.

**This is mouse ABL (Mus musculus, UniProt P00520), not human ABL1.** The deposited entry is [PDB 1IEP](https://www.rcsb.org/structure/1IEP), with the STI/imatinib ligand. The tutorial files are from the [official AutoDock Vina v1.2.7 example](https://github.com/ccsb-scripps/AutoDock-Vina/tree/v1.2.7/example/basic_docking). The upstream prepared receptor and bound ligand share a coordinate frame; the box is computed from bound-ligand heavy-atom extents plus the declared padding. The curated tutorial receptor already represents selection/preparation decisions and is not an untouched experimental structure.

`originals/` contains byte-for-byte upstream tutorial files. No input file is edited by the scientific workflow, which makes a content-addressed, read-only input snapshot in each run. `sources.json` records URLs, source identifiers and hashes. `library.sdf` is a derived file explicitly changed by BioCentricGPT: metadata were added to the original ligand and manually entered caffeine/aspirin structures were appended. Those structures are **untested chemical diversity controls**, never labeled tested inactive. Their identities/valence are checked by RDKit; no measured affinities are asserted.

The three compounds, one seed and modest exhaustiveness test software operation. They do not benchmark screening accuracy or justify an experimentally confirmed hit. The report must retain failed pose checks, poor redocking and unavailable adapters. No independent active/inactive activity dataset is included; the benchmark gate therefore remains unvalidated/exploratory.
